# About

**Xuanji (玄机)** literally means **"mysterious principles"**, referring to the hidden mechanics behind how things work.

This repository is my personal engineering laboratory where I learn technologies by building practical projects instead of only reading documentation.

Rather than creating one large application, I organize independent playgrounds to deeply understand a single technology, architecture, or design pattern.

# Philosophy

This repository follows one simple principle:

> Learn by building.

Every playground answers questions like:

- How does it work?
- Why was it designed this way?
- What problems does it solve?
- What are the trade-offs?
- How does it perform?

Whenever possible, I benchmark, compare implementations, and document my findings instead of relying on assumptions.
